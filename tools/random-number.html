How random number generator works

Generate a random integer between the minimum and maximum values, including both endpoints. Randomness comes from the browser's cryptographic random number generator when available.

Is it predictable?

The tool uses the browser Web Crypto API for random selection, but it is not intended as a substitute for specialized security or gambling systems.
